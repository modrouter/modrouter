# ModRouter

ModRouter is a router for Blazor: a replacement for the built-in `Router` with nested and named routes, reverse URL
generation, a deterministic precedence-based matcher, guards, loaders with caching, redirects and typed routes. It also has a
compatibility layer, so an existing app can adopt it without rewriting its `App.razor` or its `@page` components.

It targets .NET 8, 9 and 10 and is currently a preview (`0.1.0-preview.1`).
